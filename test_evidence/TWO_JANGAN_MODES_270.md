# Two full Jangan project modes — 2.7.0

- Tiles button retains the original full 174-region mesh export, previously verified with 5,961 environment placements. Routing and terrain-mode regression checks passed in this release.
- Landscape button was run through the public Blender operator in a new empty project, exporting source models from scratch and running the plugin's Unreal importer automatically.
- Landscape result: 174 source regions, one native Landscape, 5,961 environment placements and zero old terrain FBXs/actors.
- Six source-derived layers: Soil, Grass, DryGrass, WetSoil, Rock, Paving; yellow/dry grass and ordinary dirt are retained separately.
- 106 automated checks passed. All sampled collision traces hit; maximum measured error 0.2928cm. Padding collision excluded. One edit layer and all six target layers are allocated.
- Original Blender scene restored. Generated map hash unchanged during read-only screenshot verification. No external terrain/material repair applied.
- Real tests: Blender 5.2.2, Unreal 5.8.3 Win64. Compatible bridge binary was rebuilt from included source using BuildPlugin. Other Unreal versions and the automatic mismatch rebuild path are not end-to-end verified.
- No database spawns, gameplay, skills or prototype UI are generated by the map buttons. Landscape groups original tile textures into six ground families; it does not preserve every individual source tile texture variation. Tiles mode preserves that source style. Full-map gameplay performance is not benchmarked.
